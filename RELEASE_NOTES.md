# WeatherWall v0.1.1 - Release Notes

This update focuses on privacy, performance optimizations, and refining the overall user experience for public distribution.

### 🛡️ Privacy & Security
- **Clean Configuration**: The application now ships with a generic default configuration. All personal machine-specific paths, usernames, and automation rules have been removed.
- **First-Launch Experience**: On the first launch, users are now guided to select their own wallpaper folder, ensuring no personal data is ever exposed or pre-set.

### 🚀 Performance Optimizations
- **Instant Tab Switching**: Resolved a significant lag (2-3 seconds) when switching between tabs.
- **Efficient Memory Cleanup**: GC collections are now intelligently managed to keep the UI snappy while in use.

### 🎨 UI & UX Refinements
- **Polished Startup**: Refined splash screen timing and transitions for a premium "app launch" feel.
- **Modern Tab Design**: Switched to a clean blue border indicator for active tabs.
- **Improved Visibility**: Enhanced contrast for checkbox labels and tray icons.
- **Updated Branding**: Fully integrated new high-resolution logos and icons.

### 🔧 Fixes
- Fixed visual overlap between splash screen and main window.
- Standardized automatic configuration generation.
